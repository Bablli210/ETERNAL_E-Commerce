Motion spec · tokens and rules

Every animation, one line each.

Durationsxs 120 · s 200 · m 320 · l 600 · xl 1200 ms. Micro-feedback is xs/s, drawers and screens m, meters and counts l, the mark draw xl.
Easingstandard cubic-bezier(.2,.7,.2,1) · emphasized cubic-bezier(.16,1,.3,1) for drawers and screens · exit cubic-bezier(.4,0,1,1) · linear only for the reviews drift.
Distances and scaleRise 16 px (24 on display type) · nudge 4 px · slide 8 px · hover scale 1.03 max · parallax factor ≤ 0.2 · stagger 40 / 60 / 80 / 120 ms.
TriggersScroll reveals at 20 % visibility, once; count-ups and meters at 50 %; sticky elements on the main control leaving the viewport.
Performance budgetHero video ≤ 2.5 MB (mp4 + webm), poster ≤ 120 KB; GSAP only on templates that need it (home, PDP, finder), deferred; no animation on the LCP element except the poster fade.
ImplementationCSS custom properties for the tokens · a data-reveal utility on IntersectionObserver · GSAP + ScrollTrigger for H1, H5, D5, F3 · inline SVG stroke draw for the e∞ mark (no Lottie needed) · View Transitions API for G2 · native scroll-snap carousels · a global “Enable motion” theme setting plus prefers-reduced-motion.
